Calculateur Kinn

La page propose deux versions de calcul: la version historique basee sur la marge a partir des tokens, et une version 2 basee directement sur les credits Kinn utilises et achetes.

Version 1: prix depense = (tokens / 1 000 000) x prix du modele, puis credits Kinn = (prix depense x marge / prix Kinn credits) x 1000. Version 2: cout models = credits utilises / 50, avec une regle fixe de 50 credits Kinn = 1 $ depense, puis benefice = prix paye - cout models et marge = prix paye / cout models.

Comment les calculs sont faits

Les valeurs pre-remplies correspondent a un cas reel de creation de workflow sur Kinn: un appel `gpt-5.2` en input avec `510509` tokens et un appel `gpt-5.2` en output avec `2435` tokens.

  1. Depense models

    Pour chaque ligne, on calcule d'abord le cout reel du modele avec la formule `tokens / 1 000 000 x prix du modele`.

    Avec les valeurs pre-remplies cela donne: `(510509 / 1 000 000) x prix gpt-5.2 input` et `(2435 / 1 000 000) x prix gpt-5.2 output`.

    `Depense models` est ensuite la somme de toutes les lignes.

  2. Depense totale

    Une fois `Depense models` obtenue, on applique la marge pour obtenir ce que l'utilisateur paye.

    Formule: `Depense totale = Depense models x marge`.

    Avec la valeur pre-remplie `marge = 2.5`, on multiplie donc le cout reel par `2.5`.

  3. Credits Kinn consommes

    Une fois `Depense totale` calculee, on la convertit en credits Kinn a partir du prix Kinn pour `1000` credits.

    Formule: `Credits Kinn = (Depense totale / prix Kinn pour 1000 credits) x 1000`.

    Avec la valeur pre-remplie `Prix Kinn credits / 1000 = 50`, cela revient a dire qu'un montant de `$50` represente `1000` credits Kinn.

En resume: `Depense models` = cout reel des appels IA, `Depense totale` = prix facture a l'utilisateur, et `Credits Kinn` = equivalent de cette depense dans ton systeme de credits.
